# jakob-now

A filter-driven resume explorer. Visit the live app to browse work experience filtered by stack, skills, and date range — surfacing the most relevant entries for any given role.

**[jakob.now →](https://jakobemilandersson.github.io/jn/)**

---

## Stack

React · TypeScript · Vite · Tailwind · Zustand

---

## Run locally

```sh
git clone https://github.com/jakobemilandersson/jn.git
cd jn
pnpm install
pnpm dev
```
